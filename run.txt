Run it
Backend

Open Command Prompt / PowerShell:

cd SPILL/backend

Create the environment:

python -m venv venv

Activate it on Windows:

venv\Scripts\activate

Install everything:

pip install -r requirements.txt

Start Flask:

python app.py

You should see:

Running on http://127.0.0.1:5000
Flutter

Open another terminal:

cd SPILL/frontend

Get packages:

flutter pub get

Then:

flutter run
